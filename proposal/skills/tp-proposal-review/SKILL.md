# 教學實踐研究計畫書預審

## 這個 skill 做什麼
把一份計畫書（PDF 或 Word）與授課計畫書，依官方章節與審查評分項目，預審成一份**可執行的修改清單**。目標是降低可避免的失分，**不是預測會不會通過**（歷年通過率約 42–48%）。

## 需要的檔案
1. 計畫書（必要）
2. 授課計畫書（強烈建議；沒有就跳過跨文件一致性）
3. 歷年自己的計畫書（選用；用來檢查自我重複與延續差異）

## 步驟
1. **先跑程式檢查**，不要自己用肉眼猜頁數與數字：
   ```
   python proposal/tools/proposal_checks.py --proposal 計畫書.pdf --course 授課計畫書.pdf \
       --history 前年計畫書.pdf 前前年計畫書.pdf --names 主持人 協同主持人 -o check.md
   ```
   結果是**事實依據**，不可推翻。
2. 讀 `proposal/rubric-teaching-practice-proposal.md`。先看入口檢查（Gate），再看七個面向。
3. **建立一致性矩陣**（研究問題 × 教學策略 × 資料蒐集工具 × 分析方法 × 預期成果）。對不上的格子，就是 D 面向最重要的意見。
4. 逐項核對跨文件一致性（課程名稱、對象與年級、人數、屬性、學期、配分）。
5. 看延續性：作者近年計畫與本次的課程、方法、策略是否相近？有沒有明列差異？逐字重複落在哪些章節？
6. 輸出報告：
   - **入口檢查**：通過／不通過，附證據
   - **七個面向**：分數（1–5）、一句理由
   - **意見清單**：按 critical → major → minor；每條有位置、問題、建議
   - **建議修改順序**：先處理會被退件或直接低分的項目
   - **程式檢查原文**（附錄）

## 守則
- 只依計畫書實際內容；不假設、不杜撰文獻或數據。
- **你無法外部查證文獻**，只能核對內部一致；不得斷言文獻真偽。
- 不代筆。給方向，不給改寫段落（除非使用者明確要求）。
- 不得要求作者新增不存在的教學事實；只能指出缺什麼說明。
- 嚴重度節制。待補標記是作者的待辦，不是缺陷本身。
- 預審口吻：具體、可執行、不挑剔、不放水。

## 常見高價值發現（過往預審歸納）
- 標題主打某變項，但文獻與教學設計沒有一路貫徹。
- 動機寫「顯著」卻沒有統計依據與樣本數。
- 小樣本卻規劃兩因子混合變異數分析、因素分析。
- 研究問題或假設沒有對應的量表。
- 同一位主持人連續多年用相同方法敘述，且未說明差異。
- 課程名稱在計畫書、授課計畫書、問卷中有不同寫法。
- 授課計畫書的課程屬性與年級，與計畫書描述不一致。
- 章節編號與官方格式不一致。
